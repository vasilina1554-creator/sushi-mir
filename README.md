# Sushi Mir — сайт замовлення суші

Готовий статичний сайт для Netlify з каталогом, кошиком, формою замовлення, Telegram-повідомленнями та окремою адмін-панеллю.

## Публікація на Netlify (безкоштовний тариф)

1. Розпакуйте ZIP та завантажте папку `sushi-mir` у GitHub (новий репозиторій).
2. У Netlify оберіть **Add new site → Import an existing project**, підключіть репозиторій.
3. Build command залиште порожнім, Publish directory — `.`. Netlify автоматично прочитає `netlify.toml`.
4. У Site configuration → Environment variables додайте:
   - `TELEGRAM_BOT_TOKEN` — токен від @BotFather.
   - `TELEGRAM_CHAT_ID` — ваш chat ID або ID групи, куди надсилати замовлення.
5. Після додавання змінних зробіть redeploy.

Netlify Functions та Netlify Blobs використовуються для прийому замовлень і збереження меню. Для першого деплою переконайтеся, що Blobs доступні для сайту.

## Підключення Telegram

1. В Telegram відкрийте `@BotFather`, виконайте `/newbot` і створіть бота.
2. Скопіюйте токен та внесіть його в Netlify як `TELEGRAM_BOT_TOKEN`.
3. Напишіть своєму боту `/start`.
4. Щоб отримати chat ID, відкрийте у браузері `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` після повідомлення боту. Знайдіть `message.chat.id`.
5. Додайте це значення у Netlify як `TELEGRAM_CHAT_ID`. Для групи додайте бота в групу, напишіть повідомлення та візьміть ID групи з `getUpdates`.

Токен не можна вставляти у фронтенд або публічний GitHub — зберігайте його лише в Environment variables.

## Адмін-панель

Відкривається за адресою `/admin`. Вона зроблена без пароля, як було запрошено. **Увага: так будь-хто, хто знає адресу сайту, може відкрити адмінку та змінювати меню.** Для реального магазину варто захистити `/admin` через Netlify Identity / доступ за паролем або інший механізм авторизації.

## Важливо

- Фотографії за URL завантажуються із зовнішніх джерел. Завантажені з адмінки файли зберігаються як data URL у Netlify Blobs.
- Замовлення надсилаються лише після налаштування обох Telegram-змінних.
- Це стартовий шаблон: перед запуском додайте свої контакти, зони/вартість доставки, графік роботи та перевірте замовлення тестовим повідомленням.
